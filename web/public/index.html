How it works

No cable. No copy.

Spectacles cannot read a file from your computer, and a published lens may only talk https. So the world takes the one road that exists.

What leaves your machine

Not the cartridge.

Stays here

The cartridge

Read in this tab, by the same extractor the lens itself runs. It is never uploaded, never stored, never sent anywhere. You bring a cartridge you own; you are responsible for its legality.

Leaves, for one day

The baked world

The lens's own data file, about 1.7 MB, stored privately under your code and deleted after a day. Nobody can fetch it without the code, and the code is not stored with it.

The lens ships no game content, and neither does this page: no maps, no sprites, no text, no music. The only thing it carries is a table of addresses. Everything you see in the lens comes from your own cartridge and stays on your own glasses.

In the lens

All of Kanto, on a plate.

Every map

222 maps, indoors and out, with the original collision, warps, NPCs and trainers.

Every battle

Wild encounters, gyms, the Elite Four and the credits, with the cartridge's own numbers.

Hands

Pinch the ground and Red walks there. Pinch and drag to move the world; pull with two hands to grow it.

Tabletop to life-size

A model on the table, or a world around you for a fight. Walk it at whatever size the room allows.

Kept on the glasses

After the first code the world is stored on the Spectacles. No computer, no cable, no second visit.

Open source

The lens, the extractor and this page are one repository, built with CLAD for Spectacles.
